# Laporan Magang Sensus Ekonomi 2026

Repository ini berisi dokumentasi dan laporan kegiatan magang dalam rangka **Sensus Ekonomi 2026 (SE2026)** sebagai **Petugas Pendataan Lapangan (PPL)**.

## Informasi Kegiatan

- **Kegiatan:** Magang Sensus Ekonomi 2026
- **Peran:** Petugas Pendataan Lapangan (PPL)
- **Wilayah:** Kecamatan Karang Tengah, Kota Tangerang, Banten
- **Kelurahan:** Pedurenan dan Parung Jaya
- **Jumlah SLS:** 7 SLS
- **Tahun:** 2026

### Wilayah Penugasan

**Kelurahan Pedurenan**
- RT 6 RW 1
- RT 8 RW 8
- RT 9 RW 8
- RT 9 RW 6

**Kelurahan Parung Jaya**
- RT 3 RW 3 Sub 1
- RT 4 RW 3 Sub 2
- RT 4 RW 3 Sub 3

## Isi Repository

- `Laporan Magang SE 2026/` — laporan kegiatan magang
- `Dokumentasi Lapangan/` — dokumentasi kegiatan selama pendataan
- `Peta/` — peta wilayah penugasan
- `Surat Tugas/` — dokumen penugasan
- `Surat Keterangan Penyelesaian Tugas/` — dokumen penyelesaian kegiatan
- `Kepengurusan Karang Tengah/` — dokumen pendukung wilayah
- `Template/` — dokumen dan template pendukung

## Ringkasan

Kegiatan magang dilaksanakan melalui keterlibatan langsung dalam pendataan lapangan SE2026, meliputi penelusuran wilayah, identifikasi unit usaha, wawancara, penginputan data menggunakan CAPI, serta pemutakhiran dan verifikasi data berdasarkan kondisi lapangan.
